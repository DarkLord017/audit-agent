# Attribution

The `optimism-auditor` skill is original to this project. It is a
chain overlay for Solidity audits targeting OP Mainnet and other OP Stack
chains (Bedrock and later).

It is not a fork of `solidity-auditor`. That skill remains unmodified
third-party work; see `../solidity-auditor/ATTRIBUTION.md`.

Facts in `references/` are drawn from public OP Stack documentation and
specs (predeploys, opcode differences, fee vaults, address aliasing). They
are restated for auditors, not copied as specification text.
